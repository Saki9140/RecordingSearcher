# Efficient Music Search

This Java project improves a music store system by allowing **fast searches** of recordings in a large collection.  
The system avoids using lists and instead uses **maps and sets** for efficient data storage and retrieval.  

## Features
- Search recordings by artist, title, genre, or year range
- Check for missing recordings in a collection (CD or LP)
- Supports fast queries without sequential scanning
- Implements SearchOperations interface for structured searching
- Uses Recording objects as keys and values in maps and sets

## Purpose
The project practices:
- Efficient use of data structures (Map, Set)
- Algorithm design for fast search
- Object-oriented programming in Java
- Test-driven development using JUnit (Exercise2Test.java)
